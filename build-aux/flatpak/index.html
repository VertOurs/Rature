Rature

Your day, one line at a time. A self-hosted Flatpak repository.

Add the repository, then install:

flatpak remote-add --if-not-exists rature \
  https://vertours.github.io/Rature/io.github.vertours.Rature.flatpakrepo
flatpak install rature io.github.vertours.Rature

Updates then arrive like any other Flatpak app. A standalone .flatpak bundle is attached to each GitHub release.

Source, issues and the changelog: github.com/VertOurs/Rature. The repository is signed with the key in the .flatpakrepo.
